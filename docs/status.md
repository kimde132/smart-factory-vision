## 6. 자주 찾는 확정 수치

한 곳에서 보기 위한 사본이다. **원본이 아니다** — 어긋나면 괄호 안의 문서가 맞다.

**클래스** (`labeling-guide.md` 1-1 표가 원본. `data.yaml`은 여기서 옮겨 적는다)

| 번호 | 이름 |
|---|---|
| 0 | `bolt` |
| 1 | `nut` |
| 2 | `washer` |

**부품 치수** — 상품 페이지 규격이며 실측이 아니다 (D-007 0절)

| 부품 | 치수 |
|---|---|
| 볼트 | 머리 대변 15.9mm / 대각 18.4mm, 머리 두께 8.2mm, 기둥 M10 × 100mm |
| 너트 | 대변 15.9mm / 대각 18.4mm, 내경 M10 |
| 와셔 | 외경 19.6mm, 내경 M10 |

- 볼트 머리와 너트는 탑뷰에서 크기·모양이 같다 → 구분 단서는 **중앙 구멍 유무** 하나뿐. 그래서 **볼트는 눕혀서 배치**한다
- 너트와 와셔의 탑뷰 최대 폭 차이는 **약 6%** → 크기만으로 판단 금지. 단서는 **외곽선이 육각이냐 원이냐**

**촬영** (D-007)

| 항목 | 값 |
|---|---|
| 각도 / 프레임 | 탑뷰, 20cm × 20cm |
| 프레임 폭 상한 | **31cm** (와셔 40픽셀 확보 하한선) |
| 와셔가 찍히는 크기 | 약 **63픽셀** (`imgsz=640` 기준) |
| 기기 | 아이폰 15 Pro 광각 (웹캠 전환 시 **별도 세션**) |
| 트레이 / 배경 | 29cm × 20cm, 갈색 나무 |
| 조명 | 실내 조명(후방). 자연광은 커튼으로 차단 |

**수량** (D-008)

| 항목 | 값 |
|---|---|
| 정상 수량 | 부품당 **3개** |
| 촬영 범위 | 0~6개, 각 개수마다 **5장** |
| 빈 트레이(배경 이미지) | 전체의 **10% 이하** (D-005) |

**뒤집는 조건 숫자**

| 조건 | 값 |
|---|---|
| 너트↔와셔 상호 오분류율 (Val) | **5% 이상**이면 3종 구성 재검토 (D-004) |
| 아무것도 탐지하지 못하는 비율 | 테스트 이미지의 **10% 이상**이면 배경 이미지 비중 축소 (D-005) |
| 프레임 폭 | **31cm 초과** 시 촬영 환경 재설계 (D-007) |
