## 2. 절대 하지 말 것 (반복 확인용)

- **계획표 순서를 건너뛰고 촬영 금지** — 이름 변경 스크립트가 촬영 시각 순으로 `001`부터 번호를 붙인다. 순서가 어긋나면 `images.csv`의 개수와 실제 사진이 어긋나고, 라벨링 검수가 전부 무의미해진다
- **촬영 도중 중단하면 새 세션** (D-009 Q4·Q5) — 손 촬영이라 다시 앉으면 높이·각도가 달라진다. **삼각대가 생겨도 이 규칙은 당분간 그대로 둔다.** 규칙의 근거가 약해진 것은 맞지만, 푸는 것은 D-009 10절에 근거를 쓰고 나서 할 일이다
- **프레임 폭 측정용 사진을 데이터에 남기지 말 것** — 자를 얹고 찍은 사진이 남으면 이름 변경 스크립트가 그것을 `001`번으로 잡는다. 눈금을 읽었으면 바로 지운다
- ~~**⭐ Label Studio 클래스 등록 순서**~~ → **8/24 확인 완료.** YOLO로 내보낸 `classes.txt`·`notes.json`이 `0=bolt, 1=nut, 2=washer`로 나오는 것을 파일로 확인했다(`setup-log.md` 5-1). 대신 **라벨링 설정(XML)의 라벨 순서를 앞으로 바꾸지 말 것** — 그 순서가 곧 클래스 번호다
- **⭐ Label Studio를 `label-studio start` 로 그냥 켜지 말 것** — 반드시 **`.\scripts\start_labelstudio.ps1`**. 환경 변수는 그 프로세스에만 붙으므로, 그냥 켜면 로컬 파일 서빙이 꺼져 **사진이 전부 깨져 보인다.** 증상만 보고는 원인을 찾기 어렵다
- **단축키 1·2·3은 클래스 번호가 아니다** — 손가락 편하라고 준 키일 뿐이다. 클래스 번호는 `0, 1, 2`. 박스를 그릴 때 **키를 믿지 말고 화면에 켜진 라벨 이름을 볼 것**
- ~~s01_001에 시험용 라벨이 남아 있다~~ → **8/24 지우고 다시 그렸다**
- **⭐ s02부터는 계획표의 되감기 지점(6→0)을 조심할 것** — s01에서 정확히 여기서 틀렸다. 앞뒤가 전부 "한 개씩 빼기"인데 되감기만 "6개를 한꺼번에 빼기"라 손의 리듬이 끊긴다. **재발 방지책을 정하기 전에는 s02를 찍지 말 것** (1절 4번)

- ~~`labeling-guide.md` 3절 없이 라벨링 시작 금지~~ → **3절 작성 완료(8/23).** 대신 라벨링 중 규칙을 바꾸면 **반드시 8절 표에 기록**한다. 안 남기면 한 데이터셋에 두 규칙이 섞인다
- **`metadata/`를 `dataset/` 안으로 옮기지 말 것** — `.gitignore`가 `dataset/`을 통째로 제외한다. CSV는 실패 분석의 유일한 근거라 git에 남아야 한다

- 볼트 머리와 너트는 탑뷰에서 크기·모양이 같다 → 구분 단서는 **중앙 구멍 유무** 하나뿐. 그래서 **볼트는 눕혀서 배치**한다
- 너트와 와셔의 탑뷰 최대 폭 차이는 **약 6%** → 크기만으로 판단 금지. 단서는 **외곽선이 육각이냐 원이냐**

**촬영** (D-007)

| 항목 | 값 |
|---|---|
| 각도 / 프레임 | 탑뷰, 20cm × 20cm |
| 프레임 폭 상한 | **31cm** (와셔 40픽셀 확보 하한선) |
| 와셔가 찍히는 크기 | 약 **63픽셀** (`imgsz=640` 기준) |
| 기기 | 아이폰 15 Pro 광각 → 웹캠 **레이저 Kiyo X** (**별도 세션**) |
| 포맷 | **JPEG** (아이폰 `높은 호환성` 설정. 웹캠이 HEIC를 못 찍어 통일) |
| 아이폰 설정 | **1x (35mm 환산 24mm), 정사각 1:1, 4284 × 4284** — EXIF로 확인(8/19). 10세션 내내 고정 |
| 트레이 / 배경 | 29cm × 20cm, 갈색 나무 |
| 조명 | 실내 조명(후방). 자연광은 커튼으로 차단 |

**수량** (D-008)

| 항목 | 값 |
|---|---|
| 정상 수량 | 부품당 **3개** |
| 촬영 범위 | 0~6개, 각 개수마다 **5장** |
| 빈 트레이(배경 이미지) | 세션당 1장 = **2.9%** (D-005의 10% 이하 충족. 별도 추가 촬영 불필요) |

**세션과 파일명** (D-009)

| 항목 | 값 |

| 세션 정의 | 한 번 자리를 잡고 앉아 **중단 없이** 이어 찍은 묶음 |
