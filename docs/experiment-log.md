# 실험 로그

> 학습 실험을 하나씩 기록하는 문서. **판단 칸은 내가 쓴다.** Claude는 로그·결과 파일에서 숫자와 사실을 옮기고, 판단 칸에는 `> Q.` 질문만 넣는다.
> 질문에 답을 쓴 뒤 질문 줄을 지우고 통독한다.
>
> 한 실험의 구조: **무엇을 바꿨나(설정) → 무엇이 나왔나(결과, 사실) → 무엇을 뜻하나(해석, 판단) → 다음에 무엇을 바꿀 것인가(가설)**
> 한 번에 하나만 바꾼다. 두 개를 바꾸면 무엇이 결과를 바꿨는지 모른다.
>
> 9/6 `s01_pipe_check`는 train·val이 같은 세션이라 성능 숫자가 무의미했다. 정식 실험으로 세지 않는다 (D-010). 요약만 `status.md` 1절에 있다.

**혼동 행렬** (`confusion_matrix.png`, 세로 = 예측, 가로 = 정답)

| | 정답 bolt | 정답 nut | 정답 washer | 정답 background |
|---|---|---|---|---|
| 예측 bolt | 105 | 0 | 0 | 0 |
| 예측 nut | 0 | 105 | **3** | 0 |

- 315개 중 312개 정답. 틀린 것은 **와셔 3개를 너트로 본 것**뿐. 놓친 것(→background) 0, 헛것(background→) 0
- 너트↔와셔 상호 오분류: 와셔→너트 3 / 105 = **2.9%**, 너트→와셔 0 / 105 = 0%
- 학습 곡선 (`results.csv`): mAP50은 12 epoch에 0.99 도달. mAP50-95는 12→80 epoch에 0.84→0.91. 91~100(mosaic 꺼짐)에서 0.89~0.905로 흔들림
- val loss가 100 epoch까지 계속 내려갔다 (box 0.745→0.424, cls 3.29→0.35). 과적합 징후 없음
- 9/6 비교: mAP50-95 0.885 → 0.911. 단 9/6은 같은 세션이라 **비교 대상이 아니다**

### 3. 해석 (판단 — 내가 쓴다)

> Q. val(s04)은 train에 없는 조명 조합(천장등 없음 + 스탠드 약)이다. 그런데도 0.99가 나왔다. 이것을 "조명이 달라도 된다"로 읽어도 되는가, 아니면 s02·s03(같은 웹캠·같은 삼각대·같은 트레이)이 train에 있어서 사실상 본 것과 다름없는가? 어느 쪽인지 가르는 방법은 무엇인가?

> Q. D-004 뒤집는 조건은 "너트↔와셔 오분류 5% 이상"이고, D-010 6절은 "웹캠 사진이 val/test에 들어간 상태에서 5% 이하면 해소"다. val(s04)은 웹캠이고 2.9%다. 이것으로 D-004를 `해소`로 바꿀 것인가, test(s05)까지 보고 정할 것인가? 이유는?

> Q. 와셔 3개가 너트로 분류됐다. 그 3개가 어떤 사진의 어떤 와셔인지 아직 모른다. 그것을 알아내려면 무엇이 필요한가? (힌트: #20 추론 스크립트가 사진별 개수를 내면 `images.csv`와 대조할 수 있다)

> Q. 개수를 세는 것이 목적이다. 이 결과를 "개수 정답률"로 바꾸면 어떻게 되는가? 와셔 3개가 너트로 가면 그 사진은 너트 +1, 와셔 −1로 두 클래스가 동시에 틀린다. 35장 중 몇 장이 틀렸을 것 같은가? (정확한 수는 #20 뒤에)
