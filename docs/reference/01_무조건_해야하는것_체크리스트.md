## A-6. SQL Server + SSMS + ODBC Driver 18 설치 및 **연결 성공까지** 확인

이 항목이 6주 프로젝트에서 가장 시간을 잡아먹을 위험이 크다. **5주차가 아니라 지금 끝낸다.**

- [ ] SQL Server Developer Edition 설치
- [ ] SQL Server Management Studio(SSMS) 설치
- [ ] **Microsoft ODBC Driver 18 for SQL Server** 별도 설치 (SQL Server를 깔아도 자동으로 안 깔릴 수 있음)
- [ ] **혼합 모드 인증(Mixed Mode) 활성화** ← 안 하면 pyodbc가 로그인 못 한다
- [ ] **SQL Server Configuration Manager에서 TCP/IP 프로토콜 사용으로 변경 후 서비스 재시작** ← 이것도 안 하면 연결 실패
- [ ] SSMS에서 데이터베이스 `vision_inspection` 생성
- [ ] 프로젝트 전용 로그인 계정 생성 및 해당 DB 권한 부여
- [ ] **Python에서 pyodbc로 접속 성공 확인** ← 여기까지 해야 완료

```python
# scripts/check_db.py
import pyodbc
from sqlalchemy import create_engine, text
from urllib.parse import quote_plus

print([d for d in pyodbc.drivers() if "SQL Server" in d])  # 'ODBC Driver 18 for SQL Server'가 보여야 함

pwd = quote_plus("실제비밀번호")   # 비밀번호에 @ ! ; 등이 있으면 반드시 인코딩해야 한다
url = (
    f"mssql+pyodbc://db_user:{pwd}@localhost/vision_inspection"
    "?driver=ODBC+Driver+18+for+SQL+Server"
    "&TrustServerCertificate=yes"
)
engine = create_engine(url)
with engine.connect() as conn:
    print(conn.execute(text("SELECT @@VERSION")).scalar())
```

**완료 판정:** SQL Server 버전 문자열이 출력된다.

**꼭 알아야 할 함정 3가지**
1. **ODBC Driver 18은 기본값이 `Encrypt=yes`다.** 로컬 개발용 자체 서명 인증서는 신뢰되지 않아 연결이 거부된다 → `TrustServerCertificate=yes`가 반드시 필요하다. (드라이버 17에서는 기본값이 달라서, 17 기준 예제를 그대로 따라 하면 실패한다.)
2. **혼합 모드 인증 + TCP/IP 활성화**를 안 하면 `Login failed` 또는 연결 자체가 안 된다.
3. **비밀번호 특수문자**는 연결 문자열에서 깨진다 → `urllib.parse.quote_plus`로 감싼다.

**대안(막힐 경우):** Windows 인증으로 우회할 수 있다.
`mssql+pyodbc://@localhost/vision_inspection?driver=ODBC+Driver+18+for+SQL+Server&trusted_connection=yes&TrustServerCertificate=yes`
다만 계정·권한·연결 문자열 경험은 포트폴리오 설명거리이므로 **SQL 인증을 우선 시도**한다.

# C. 데이터·학습 단계에서 무조건 지킬 것

## C-1. 촬영 세션 기준으로 Train/Val/Test 분리 ★

- [ ] **같은 촬영 세션의 이미지가 Train과 Test에 동시에 들어가지 않게** 분리

**이유:** 연속 촬영한 거의 같은 이미지가 Train과 Test에 나뉘어 들어가면(=데이터 누수), mAP 0.95 같은 숫자가 나오지만 **실제로는 전혀 동작하지 않는 모델**이 된다. 그리고 면접에서 "어떻게 나눴나요?"는 거의 확정적으로 나오는 질문이다.
**절대 하면 안 되는 것:** 전체 이미지를 랜덤 셔플해서 8:1:1로 자르기.

## C-2. 빈 트레이는 "배경 이미지"로 넣는다

- [ ] 빈 트레이 이미지는 **라벨 파일을 비워두거나 만들지 않는다** (`empty` 클래스를 만들지 않는다)

**이유:** YOLO에서 "아무 객체도 없는 이미지"는 배경(negative) 샘플로 취급되어 오탐을 줄이는 역할을 한다. `empty`라는 클래스를 만들면 "빈 공간에 바운딩 박스를 치라"는 모순된 학습이 된다.
**비율:** 전체의 5~10% 정도가 적당하다.

## C-3. 노트북에서 1~3 Epoch 스모크 테스트 후에 Colab 본 학습

- [ ] 로컬에서 `epochs=2, imgsz=320, batch=2, device="cpu"`로 실행하여 경로·라벨 형식·클래스 개수 오류만 확인
- [ ] 그 다음 Colab에서 본 학습

**이유:** Colab GPU 시간을 경로 오타 디버깅에 쓰지 않기 위해서다.

| # | 필수 기능 | 완료 판정 |
|---|---|---|
| 1 | FastAPI: 서버 시작 시 YOLO 모델 **1회만** 로딩 | 요청마다 로딩되지 않음(추론 시간 로그로 확인) |
| 2 | `POST /api/inspections`: 이미지 수신 → 추론 → 판정 → 저장 | Swagger(`/docs`)에서 이미지 업로드로 OK/NG 반환 |
| 3 | 부품별 **개수** 비교 판정 로직 (`Counter` 사용) | 기준 수량 대비 부족/초과 모두 NG 처리됨 |
| 4 | 원본·결과(바운딩박스) 이미지 파일 저장 | `storage/` 에 파일 생성 |
| 5 | MSSQL `inspections` 테이블에 검사 이력 저장 | SSMS에서 `SELECT`로 행 확인 |
| 6 | Alembic 마이그레이션으로 테이블 생성 | `alembic upgrade head` 성공 |
| 7 | `GET /api/inspections`: 날짜·결과 필터 조회 | 필터가 실제로 동작 |
| 8 | `GET /api/inspections/export`: `.xlsx` 반환 | Excel로 열림 |
| 9 | WPF: 카메라 영상 표시 + 검사 시작 + 다음 제품 | 버튼 흐름 동작 |
| 10 | WPF: OK/NG, 탐지 부품, 누락 부품, 결과 이미지 표시 | 화면에 표시됨 |
| 11 | WPF: DataGrid 검사 이력 조회 + Excel 저장 | 파일 저장 대화상자로 저장됨 |
| 12 | **추론 시간(ms)과 모델 버전을 DB에 저장** | 컬럼에 값이 들어감 |
| 13 | 예외 처리: 서버 다운 / 카메라 없음 / 타임아웃 / 버튼 연타 방지 | 앱이 죽지 않고 메시지 표시 |

### 구현 시 무조건 지킬 기술 사항

- [ ] **DB 비밀번호를 코드에 직접 쓰지 않는다.** `.env` + `pydantic-settings`, `.env`는 `.gitignore`.
- [ ] **`.env.example`은 커밋한다.** (키 이름만, 값은 비움)
- [ ] **WPF의 카메라 캡처와 HTTP 요청은 UI 스레드를 막지 않게 한다.** `async/await` 사용. 동기로 짜면 검사 중 화면이 얼어붙는다.
- [ ] **이미지는 DB에 넣지 않고 파일로 저장하고 경로만 DB에 넣는다.** (면접 단골 질문이며, 이미 계획서에 결정되어 있음)
- [ ] **`detected_parts`/`missing_parts`는 `NVARCHAR(MAX)`에 JSON 문자열로 저장.** SQL Server에는 PostgreSQL의 `JSONB`에 해당하는 것이 없다.
- [ ] **`inspected_at`은 `DATETIME2`.** `DATETIME`은 정밀도가 낮다.

`00_사전준비.md`에서 이미 1건을 잡았고, 문서를 검토하며 4건을 추가로 발견했다.

| 2 | `python-multipart` | **패키지 목록에 없음.** FastAPI의 `UploadFile`은 이 패키지가 없으면 런타임 에러 | **추가 (필수)** |

### 추가로 인지만 하고 넘어갈 것

- **Ultralytics 라이선스는 AGPL-3.0이다.** 개인 포트폴리오를 GitHub에 공개하는 것은 문제없다. 다만 "상용 제품에 넣으려면 상용 라이선스가 필요하다"는 점은 알아두면 면접에서 가산점이 된다.
- **본 학습은 Colab, 추론은 로컬**이라는 구조는 약점이 아니라 실무 표준(학습 환경/배포 환경 분리)이다. 그대로 설명하면 된다.
